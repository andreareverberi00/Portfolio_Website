# Call of Duty: Modern Warfare

Call of Duty: Modern Warfare is a first-person shooter game where I contributed to the development of core gameplay systems. The project focused on delivering an immersive combat experience with realistic weapons, tactical gameplay, and a compelling narrative campaign.

## Gameplay

The game features a robust weapon handling system with realistic recoil patterns and ballistics. Players can engage in both single-player missions and multiplayer combat across various maps and game modes. The combat AI uses advanced behavior trees to create challenging and dynamic enemy encounters that adapt to player tactics.

I implemented several key systems including the weapon attachment framework that allows players to customize their loadouts with various scopes, grips, and other modifications that affect weapon performance in meaningful ways.

## Visual Style

The game employs a photorealistic visual style with detailed environments, advanced lighting, and high-fidelity character models. Special attention was given to weapon models and animations to ensure authentic handling and feel during gameplay.
